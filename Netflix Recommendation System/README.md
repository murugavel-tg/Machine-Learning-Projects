# Netflix Recommendation System Using SVD

## Project Overview

This project develops a personalized Netflix movie recommendation system using collaborative filtering and Singular Value Decomposition (SVD).

The system learns patterns from historical customer–movie ratings and predicts ratings for movies that a selected user has not previously rated.

The project covers the complete workflow from Netflix rating-data preprocessing to model evaluation and personalized movie recommendations.

---

## Objective

The main objective is to build a recommendation system that can:

- Process Netflix rating data
- Prepare user–movie interactions
- Apply collaborative filtering
- Train an SVD recommendation model
- Evaluate predicted ratings using RMSE and MAE
- Generate personalized movie recommendations
- Map recommended movie IDs to movie titles

## Data Preprocessing

The Netflix rating data requires preprocessing because the original file associates a movie ID with the ratings that follow it.
The preprocessing workflow includes:
1.	Identifying movie boundaries. 
2.	Assigning the appropriate movie ID to each rating. 
3.	Creating the Movie_Id column. 
4.	Removing rows with missing ratings. 
5.	Filtering less-rated movies. 
6.	Filtering inactive customers. 
7.	Preparing the cleaned rating data for collaborative filtering. 
The movie metadata is later joined with the recommendation results so that movie IDs can be displayed as movie names.

---

## Recommendation Approach

The project uses collaborative filtering.
Collaborative filtering learns from historical interactions between users and movies.
Instead of relying only on movie metadata, the model learns patterns from customer rating behavior.
The recommendation algorithm used is:
SVD — Singular Value Decomposition

---

## User–Movie Rating Data

The cleaned rating data contains:

- Customer ID 
-	Movie ID 
-	Rating 

These user–movie interactions are used by the SVD algorithm to learn latent patterns in customer preferences.
The model can then estimate how highly a customer may rate movies they have not previously rated.

---

## SVD Model

The SVD model is implemented using the Surprise recommendation-system library.The model is trained using a sample of 100,000 ratings in the notebook.
SVD performs matrix factorization to learn latent representations of users and movies.The learned representations are used to predict user ratings for movies.

---

## Model Evaluation

The SVD model was evaluated using 3-fold cross-validation.
Two evaluation metrics were used:
-	RMSE — Root Mean Squared Error 
-	MAE — Mean Absolute Error 
Lower values indicate smaller prediction errors.

## Limitations

The current recommendation system has several limitations:
-	The evaluation uses a sample of the available rating data. 
-	The system relies primarily on collaborative filtering. 
-	New users with little or no rating history may be difficult to recommend for. 
-	New movies with limited rating history may also be difficult to recommend accurately.
-	Predicted ratings are estimates rather than guaranteed user preferences. 
-	The current implementation focuses on rating prediction rather than ranking-specific metrics.
