# Netflix Recommendation System Using SVD

## Project Overview

This project develops a personalized Netflix movie recommendation system using collaborative filtering and Singular Value Decomposition (SVD).

The system learns patterns from historical customer–movie ratings and predicts ratings for movies that a selected user has not previously rated.

The project covers the complete workflow from Netflix rating-data preprocessing to model evaluation and personalized movie recommendations.

---

## Objective

The main objective is to build a recommendation system that can:

- Process Netflix rating data
- Prepare user–movie interactions
- Apply collaborative filtering
- Train an SVD recommendation model
- Evaluate predicted ratings using RMSE and MAE
- Generate personalized movie recommendations
- Map recommended movie IDs to movie titles
